# MA Intel Platform
Forensic Diligence, Provenance Tracking & M&A Intelligence Platform.

## Core Mandate
Zero-Trust Data Assurance, Provenance Verification, and Structured Strategic Analysis.

## Auditable M&A Diligence Demo
The repository includes a fully fictional diligence case scored across market position, product maturity, dependency resilience, and risk profile. Its reports show confidence-weighted criterion scores, source references and timestamps, conflicting findings, open questions, and the SHA-256 hash of the source dataset.

```bash
python scripts/compute_diligence.py
pytest tests/
```

The demo is illustrative only and is not an investment recommendation or a real diligence finding. Keep real deal-room and client information out of this public repository; follow the [data classification policy](docs/DATA_CLASSIFICATION_POLICY.md).
